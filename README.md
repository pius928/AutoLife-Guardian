AutoLife Guardian

Team: Team Sentinel AI  
Hackathon them : AI AUTOMATION IN DECISION MAKING, MARCH 18-19, 2026  

AutoLife Guardian is an AI-powered web application that prevents poor daily decisions by evaluating planned actions in real time. It analyzes the impact on money, time, and personal goals and responds with Approve, Deny, or Conditional guidance. Users can override decisions, but the system tracks consequences to help them build smarter habits.

Features
- Real-time decision evaluation: Approves or blocks actions before they happen  
- Behavior tracking: Learns user patterns and provides personalized guidance  
- Override with accountability: Users retain freedom, but consequences are recorded  
- AI integration: GROQ, DEEPSEEK, with fallback for offline resilience  
- Admin governance: Manage users, rules, and risk watchlists  
- Statistics & charts: Tracks daily/monthly habits and life score trends
